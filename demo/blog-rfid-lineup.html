Winning RFID lineup

April 2019

← Back to blog

A look at Pinnpoint's RFID-capable duplex laser printing range — and where smart labelling adds the most value in the warehouse.

Not every operation needs a separate tagging station to get the benefits of RFID. Pinnpoint's approach is to build a UHF inlay straight into the sheeted labels and documents a team already prints, so item-level visibility becomes part of the existing pack-and-ship flow rather than an extra process at the bench.

One range, three jobs

The RFID line-up is built around the documents warehouses handle every day, each with a UHF inlay encoded as it is produced:

  • Shipping label + packing list — combined in a single sheeted document, readable on arrival
  • Shipping & return document — outbound label and return label on one RFID document, so returns are tracked as cleanly as dispatches
  • Pallet label — for tracking full loads through the warehouse and out to the dock

Driven by PIM

Behind the range sits the Pinnpoint Integration Module (PIM), which merges shipping and document data into a single duplex PDF, encodes the embedded inlay, and connects to the ERP and WMS systems that hold the order data — so RFID labels are generated straight from the source and printed on RFID-capable duplex laser printers.

The result is smart labelling that adds value where it matters — receiving, put-away, picking and dispatch — without asking the team to learn a new bench process or buy proprietary hardware.
