Network

Does PIM connect to the internet?

Only in two ways. PIM sends each sheet to the printer you choose: over your local network on port 9100 (TCP) or port 21 (FTP), or through the Windows print queue. And once a day, PIM downloads one small file, https://pinnpt.com/pim/version.json, over HTTPS (port 443) to see whether a newer version exists. That request sends no data about you, your PC or your shipments. PIM has no licence check, no usage statistics and no crash reports.

Does PIM open any ports or accept incoming connections?

No. PIM opens no listening port and accepts no incoming connections. It only connects out: to your printer and to the version check.

Does PIM work offline?

Yes. Printing needs only your local network to the printer. Without internet, the version check is skipped and printing carries on.

Does PIM work behind a proxy?

Yes. The daily version check uses the Windows proxy settings, including automatic proxy scripts (WPAD and PAC files) and proxies that need a sign-in. The background task runs under the SYSTEM account, which has its own proxy settings. If the check cannot get through, PIM skips it and printing carries on.

Data and privacy

Which files does PIM read?

Only PDF files saved directly in the two folders you set: one for shipping labels and one for packing lists (C:\PIM\labels and C:\PIM\lists by default). PIM does not read subfolders or any other type of file. If you pair files by order number, PIM reads the text inside those PDFs to find it.

What happens to a PDF after it prints?

PIM moves the label and the packing list to the archive folder (C:\PIM\archive by default). If you leave the archive folder blank, PIM deletes them only after the printer confirms the sheet has printed; otherwise it keeps them in output\unconfirmed. The merged sheet stays in the output folder.

What does PIM store on the PC?

Everything stays in the PIM folder (C:\PIM by default): the settings file PIM.ini, the merged sheets (output), the original PDFs (archive), an activity log (logs\pim.log) and a 24-hour record of the jobs sent, so that no sheet prints twice. The chosen language is saved in the user’s Windows profile. PIM never deletes the output, archive or log: you decide how long to keep them.

Does any data leave the PC?

No. Nothing goes to Pinnpoint or anyone else. The daily version check sends no data; as with any web visit, the server that hosts pinnpt.com sees your internet address.

Who is responsible for the personal data in the label PDFs?

Your business. The label PDFs are made by your systems and stay on your PC and your printer; Pinnpoint never receives them. PIM adds no user ID or tracking ID.

Systems and permissions

Does PIM connect to our WMS or ERP?

PIM never connects to, reads or changes your WMS or ERP. It picks up the label PDFs your system already makes.

Does PIM need admin rights?

To install PIM for everyone who uses the PC, yes; this also lets PIM start in the background when the PC is switched on. To install it only for yourself, no. Running PIM never needs admin rights.

How does PIM run?

As a normal Windows program with a tray icon. With the start-up option, which is on by default, the installer adds a Windows Task Scheduler task called “Pinnpoint PIM”. It runs PIM in the background under the SYSTEM account from the moment the PC is switched on, before anyone signs in, and restarts PIM if it stops. It is a scheduled task, not a Windows service.

Can PIM read from a network folder?

You can set any folder path, including a network path such as \\server\share. The background task runs as the SYSTEM account, so the share must give the PC’s computer account access.

What should we allow in our antivirus or endpoint tools?

For an all-users install, the program is in C:\Program Files\PIM Configurator and the program that runs is PIM Configurator.exe. To print to printers installed in Windows, it also runs SumatraPDF-3.4.6-32.exe, which ships inside the PIM program folder. PIM’s data folder is C:\PIM by default.

Deployment

Which operating systems are supported?

Windows, 64-bit (x64).

Can PIM be installed silently, or pushed with Intune or Group Policy?

Yes. For everyone who uses the PC, run PIM-Setup.exe /S /allusers with administrator rights: PIM installs in C:\Program Files\PIM Configurator, creates the PIM folder C:\PIM and adds the start-up task. For one user without admin rights, run PIM-Setup.exe /S /currentuser. To uninstall silently, run "C:\Program Files\PIM Configurator\Uninstall PIM Configurator.exe" /S /allusers.

With Intune, add PIM as a Windows app (Win32) with these commands, and detect it by the file C:\Program Files\PIM Configurator\PIM Configurator.exe. Microsoft Configuration Manager uses the same commands. Group Policy software installation accepts only MSI packages, so with Group Policy, run the install command from a computer start-up script.

Can we set up many PCs the same way?

Yes. Set up PIM on one PC, then copy its settings file, C:\PIM\PIM.ini, to the same place on the other PCs. The installer never overwrites an existing PIM.ini, so you can copy it before or after installing. If the printers have different names on each PC, choose the printer in PIM on each one.

How do we uninstall PIM?

Uninstall it from Windows Settings, under Apps. This removes the program, its shortcuts and the start-up task. Your PIM folder (C:\PIM) is kept on purpose, with its labels, archive, log and settings; delete it by hand to remove everything.

Printing

How does PIM send jobs to the printer?

In one of three ways, chosen in PIM: through any printer installed in Windows, using its normal driver; straight to the printer’s network address on port 9100, where PIM asks the printer to confirm each finished sheet; or by FTP upload to the printer. PIM always asks for two-sided printing on the sheet size you set (A5, A4 or Letter).

Which printers does PIM work with?

Duplex laser printers. If you need one, contact your business equipment dealer.

PIM prints to any printer installed in Windows, or straight to a network printer by its IP address. For direct printing the printer must print PDF files itself; PIM checks this before it sends anything.

Updates and support

How are updates delivered?

PIM checks once a day and shows a notice when a newer version is out, with a link to this website. Nothing installs by itself: you download and run the new installer when it suits you. Blocking pinnpt.com/pim/version.json turns the check off without affecting printing.

How long is PIM supported?

Pinnpoint provides support and security updates for PIM free of charge, with no end date.

Where are the release notes?

On the PIM page, with each new version. PIM 3.1 needs no Java: everything it uses is in the installer.

Security

How do we report a security problem?

Email sales@pinnpt.com with “Security” in the subject line. The same contact is published in our security.txt file.

Which third-party components does PIM use?

Electron 44 (MIT), pdf-lib (MIT), PDF.js (Apache 2.0), basic-ftp (MIT), ini (ISC), pdf-to-printer (MIT) and SumatraPDF 3.4.6 (GPL-3.0, unmodified, run as a separate program). The full notices are in THIRD-PARTY-NOTICES.txt in the PIM program folder. A machine-readable component list (CycloneDX SBOM) is available from sales@pinnpt.com.

Has PIM been security tested?

Yes. The components PIM ships were scanned for known vulnerabilities in November 2026, and none were found. PIM’s window runs sandboxed and loads only its own files, and its printing, pairing and file handling are covered by automated tests.
