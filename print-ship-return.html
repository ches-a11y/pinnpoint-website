How it works

Print, apply, streamline returns

One duplex document does the work of three — the shipping label, the packing list and the return label, ready in a single pass.

1

Print

Generate the combined shipping label, packing list and return label in nShift Transsmart, then print it double-sided on a standard duplex laser printer.

2

Apply

Apply the label to the box. The shipping label and packing list are ready on the outside; the return label is printed in, waiting for when it is needed.

3

Streamline returns

When a customer needs to send something back, the return label is already in the box — no reprints, no waiting and no extra admin.

Three documents, one sheet

  • Nothing to match. Label, packing list and return label all come from one document, so they always belong together.
  • Returns ready in advance. The return label is built in, so customers can send items back without a reprint.
  • Fewer touches at the bench. One duplex sheet replaces separate labels, slips and return forms.
